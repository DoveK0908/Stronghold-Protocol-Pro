# 后台管理

大厅底部的「后台管理」打开独立服主管理面板。此功能不授予普通玩家权限，也不以玩家通行密码、名字或客户端的服主标记作鉴权。

## 可管理的范围

- **玩家数据**：汇总本实例保留的编号独占、上传图片和当前会话。支持搜索、分页以及对本页选择项批量重置。
- **编号独占**：释放或重新分配已有的「名字 + 四位编号」独占。不同名字可使用同一编号，未改为全服唯一数字。目标玩家必须已存在于服务器数据中；复制玩家列表的完整标识作为目标。
- **上传头像／名片**：预览并删除服务器保存的图片，清除引用。图片按内容去重；单独删除共享图片会影响全部引用者，操作前须确认。
- **反馈管理**：查看匿名反馈；每条反馈的「维护者回复」和「修改状态」按钮分别打开独立弹窗，确认后仅处理该条反馈，不依赖勾选。回复支持多行，上限 1000 字；状态默认选中当前值。多选只保留删除整条讨论，不提供批量回复或批量改状态。
- **操作记录**：本进程内最近 500 次批量写操作的时间、动作与成功数量；不保存密码、密钥、cookie、原始玩家 uid 或反馈作者身份。重启后此操作记录清空，不是持久审计系统。

每页最多选择 50 项，操作须二次确认，逐项显示结果；一项拒绝不等于整批失败。重置玩家数据不是删除账号：游戏目前没有中央持久账号库。

编号的释放与重新分配会带上列表时的持有者与时间快照；若该项在此期间已被他人占用或改回，服务端返回 `CONFLICT` 并保持现状，不会覆盖新的持有者。列表过期时刷新页面即可取得新快照。玩家重置中的图片删除无法回滚：文件删除失败时结果标为失败并附 `partial`／`removed`，其余步骤（清除独占、清理房间外资料）不再继续，刷新后可看到实际剩余状态。

**战绩、成就、等级及浏览器偏好仍保存在玩家本地，后台不能远程读取或清空。** 在房间中的玩家不能重置或重新分配身份；先离开房间。涉及共享图片的玩家重置拒绝执行，须单独审核图片。重置不修改正在运行的对局或模拟。编号重新分配后，受影响玩家重新连接／完成 hello 才采用新身份。

## 配置与安全

使用现有 `SP_OWNER_FILE` 指向服主配置，内容为 `names` 数组和 `keySha256`（服主密钥的 SHA-256 十六进制摘要）。配置文件应只允许运行服务的用户读取，勿放入静态目录或版本库。没有有效配置时后台拒绝登录。界面输入原始服主密钥，不是文件里的摘要。

仅在 HTTPS 或受信任的本机环境中使用后台。直连按 socket 的实际 HTTP/HTTPS 协议和 Host 严格检查 Origin。若使用 TLS 反向代理，须明确设置 `SP_ADMIN_ORIGIN=https://你的实际域名`，含非默认端口时一并填写；不会信任客户端提供的 Forwarded 协议头来放宽检查。不要为了登录修改为任意来源。

登录生成 10 分钟短时会话，cookie 为 HttpOnly、SameSite=Strict、路径 `/api/admin`；HTTPS 使用 Secure。写请求还须同源 Origin、JSON、会话 CSRF 与明确确认字段。浏览器不把密钥或 CSRF 写入本地存储；关闭面板会尝试退出。权限配置轮换、失效后旧会话被撤销。服务端限流、限制请求体、分页与批量大小，不提供任意文件路径、SQL 或命令执行。

`SP_FEEDBACK_PASSWORD` 仅控制旧的反馈板维护者入口；未显式配置时不再使用内置默认密码。统一后台通过服主鉴权直接管理反馈，不依赖这个旧入口。玩家匿名发帖、回复及凭自己的随机 secret 修改／撤回不受影响。

此面板管理游戏内 `/api/feedback`。部署模板中另有 SQLite 的 `/feedback/` 服务，不属于这个实例的管理面板。

## 反馈板与公告

反馈列表使用主要空间，顶部「提出反馈」按钮打开独立输入弹窗；取消保留草稿，成功发布后收起输入并定位新帖。状态分栏、匿名讨论与作者编辑／撤回保留。

现有公告已按维护者要求清空为 `data/announcements.json` 的空数组。空公告不会自动打开；后续文案由维护者另行提供，不从开发日志自动生成。

## 交付边界

本批为本地源码修改，未自动提交、推送、打包或部署。未运行浏览器或启动服务；视觉和真实反向代理环境须在单独授权后验收。部署时需同时更新服务端模块、前端与公告数据，并依照部署 SOP 备份状态及核对配置；仅换前端不会获得后台 API。
